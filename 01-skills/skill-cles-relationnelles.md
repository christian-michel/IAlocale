# Clés relationnelles

Ce fichier est un point d'entrée **volontairement vide** — à remplir par
l'utilisateur, pas par l'agent (même principe que
`skill-personnalite-et-sagesse.md` : ne jamais fabriquer un contenu par
défaut à la place de ce qui doit être explicitement confié).

Tant qu'aucune clé n'est écrite ici, `skill-persona-relations-humaines`
reste neutre sur les questions relationnelles plutôt que d'improviser un
positionnement.

## Ce qui est attendu ici, une fois confié

Les clés de lecture et de positionnement de l'utilisateur : comment
recevoir une information relationnelle, comment la décortiquer, quelle
posture adopter avant de construire une réponse. **Pas des citations**
(celles-ci vont dans `06-data/sagesse/citations-sages/`) — des règles de
méthode, propres à l'utilisateur.

## Révision

Ce fichier peut être révisé par l'agent, mais uniquement via le
mécanisme d'auto-implémentation existant (`skill-ameliorateur-systeme`
→ `auto-implementer.js`), jamais en modification directe — voir
`skill-persona-relations-humaines.md` pour le détail.
